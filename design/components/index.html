Components

Each component of the screens, in each state that matters: default, hover, and focus. The look is dark only, and no control can be disabled. Hover and focus show here with the classes is-hover and is-focus, which only the gallery has.

  • Top bar The bar on every page: the logo, the tabs, and the Shade by switch on the right.
  • Shade by switch Two links to the same page: "€ cost" without a query, and "craft time" with ?shade=time.
  • Primary action The one action of a page that stands out: accent fill, dark label.
  • Links Text links use the accent colour with no underline.
  • Panel A bordered box with a head: an h1 with a muted sub on the left, the primary action on the right.
  • Overview table One row per project: the name with the repository after it, then numbers in mono, right aligned.
  • Phase mix bar and legend A bar split by phase, in the phase colours, with the share in its title.
  • Summary tiles The totals of a project above its grid: a muted label, a big mono value, and a faint line under it.
  • Crumbs The path back above a project page: "Projects / "..
  • Grid Rows × phases in mono.
  • Notice A notice sits under the panel head.
  • Note Faint text at the bottom of a panel that explains how to read it.
